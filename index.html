Guía de Publicación e Integración Web

Sigue estos pasos sencillos para hospedar este sistema de forma 100% gratuita y publicarlo en tu sitio institucional.

Opción 1: Publicar en GitHub Pages (Recomendado)

Te dará un enlace web directo accesible por todos los profesores.

  1. Crea un repositorio público en GitHub.com (ej. reservas-prepatec).
  2. Sube este archivo guardándolo obligatoriamente como index.html.
  3. Ve a la pestaña Settings (Configuración) > Pages en tu repositorio.
  4. En Branch (Rama) selecciona main o master y haz clic en Save.
  5. ¡Listo! En 1 minuto tendrás una URL web pública como:
    https://tu-usuario.github.io/reservas-prepatec/

Opción 2: Incrustar en Google Sites

Inserta la herramienta dentro del portal de tu departamento de PrepaTec.

Método A (Si ya publicaste en GitHub Pages):

  1. En tu editor de Google Sites, dirígete a la sección Insertar > Incrustar (</>).
  2. Selecciona la pestaña Mediante URL e introduce la URL de GitHub Pages.
  3. Ajusta el tamaño del recuadro para cubrir el alto de la pantalla.

Método B (Insertar código directo en Google Sites):

  1. En Google Sites, haz clic en Insertar > Incrustar (</>).
  2. Selecciona la pestaña Incrustar código.
  3. Abre este archivo HTML con el Bloc de notas o VS Code, copia todo el código y pégalo.
  4. Haz clic en Siguiente > Insertar.
Sincronización en Tiempo Real en la Nube

Las reservaciones ahora se guardan automáticamente en la nube. Cualquier profesor o usuario que ingrese a la página verá los mismos datos en tiempo real de forma inmediata en cualquier dispositivo.
